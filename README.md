# E-Commerce Analytics Dashboard

Solução completa de Business Intelligence e Data Analytics para acompanhamento estratégico de e-commerce, integrando pipeline de dados (ETL em Python) a dashboards interativos no Power BI com análise avançada de retenção (Cohort).

## Dashboards

* **Visão Geral de E-Commerce:** Acompanhamento de indicadores macros de desempenho (GMV, Churn Rate, Ticket Médio) e evolução temporal de vendas.
* **Matriz de Cohort (Retenção):** Análise do ciclo de vida e comportamento de recompra dos clientes mês a mês, agrupados pela safra da primeira compra.
* **Desempenho de Produtos:** Mapeamento dos produtos mais vendidos, curva de participação por categoria (Percentual de Venda) e detalhamento operacional do catálogo.

## Arquitetura e Tecnologia

* **Fonte de Dados:** Excel / Arquivos Flat
* **ETL :** Python (Pandas)
* **Modelagem:** Power Query & DAX
* **Visualização:** Power BI
